# What's for Dinner?

A simple ingredient-based dinner idea generator.

## What it does

- Enter ingredients you already have in the fridge, freezer, or pantry.
- Filter by maximum cooking time, cooking method, and dietary preferences.
- Get dinner ideas ranked by how closely they match your available ingredients.
- See what you already have versus what you would still need.
- Open each meal card for simple cooking directions.
- Use **Surprise Me** when you do not want to choose.

## Run it locally

No installation is required. Open `index.html` in a web browser.

## Publish with GitHub Pages

Because this is a static HTML/CSS/JavaScript project, it can be hosted directly with GitHub Pages from the repository branch containing `index.html`.

## Project structure

- `index.html` — app layout
- `styles.css` — visual styling
- `app.js` — meal data, ingredient matching, filters, and rendering
